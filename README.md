# 📚 Sistema de Biblioteca

Sistema de gerenciamento de biblioteca desenvolvido em **Java** utilizando os conceitos de **Programação Orientada a Objetos (POO)**.

O projeto simula o funcionamento de uma biblioteca, permitindo o gerenciamento de livros, usuários e empréstimos, aplicando boas práticas de modelagem e organização de software.

---

## 🚀 Funcionalidades

- Cadastro de livros
- Cadastro de usuários
- Realização de empréstimos
- Controle de devoluções
- Validação das regras de empréstimo
- Tratamento de exceções personalizadas

---

## 🛠️ Tecnologias Utilizadas

- Java
- Programação Orientada a Objetos (POO)
- IntelliJ IDEA

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de praticar os principais conceitos da Programação Orientada a Objetos em Java, simulando um sistema simples de gerenciamento de biblioteca para consolidar conhecimentos sobre modelagem de classes, regras de negócio e organização de código.
